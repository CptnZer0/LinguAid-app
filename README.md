# LinguAid

LinguAid is the Android app for the LinguAid glove. It reads Filipino Sign Language signs from the glove over Bluetooth, shows them as a sentence, and speaks them in Filipino or English.

Made at Landy National High School, Division of Marinduque, MIMAROPA.

This repository only holds the app file.

## Install on an Android phone

1. On the phone, open this link: [download LinguAid.apk](https://github.com/CptnZer0/LinguAid-app/releases/latest/download/LinguAid.apk)
2. Open the downloaded file. If Android asks, allow installing from this source.
3. Open LinguAid and allow Nearby devices when asked.

The app needs the LinguAid hub. It works offline, with no accounts, and it does not use the internet.

To update, install the new file over the old one. Your saved samples stay. Uninstalling deletes them, so copy them to a laptop first.
